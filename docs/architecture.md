# Architecture

Inception keeps reusable workflow instructions in `skills/`. The initial workflows are `plan`, which returns a plan without edits, and `zensical-docs`, which creates or improves a Zensical documentation site in the current repository. The root is directly loadable by both hosts through `.codex-plugin/plugin.json` and `.claude-plugin/plugin.json`. Claude Code's marketplace catalog exposes this root plugin to GitHub installs. The build copies every shared skill into self-contained packages under `dist/`, beside each platform's native manifest. `platforms/` contains the standalone package manifests and guidance. `agents/` reserves shared Markdown instruction bodies; it is not automatically loaded by either platform. `scripts/`, `tests/`, and `.github/` support packaging and repository checks. Generated `dist/` output is ignored by Git.

The version is maintained once in `package.json`; the build injects it into native manifests. The generated bundles do not depend on files outside their own directory.
